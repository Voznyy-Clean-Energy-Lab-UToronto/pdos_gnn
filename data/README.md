# Data

This directory contains small reference/example data.

## Kept in git

| Path | Contents |
|---|---|
| `data/materials_prop.csv` | Materials Project id/formula/band-gap/e-above-hull metadata for the full materials set used. |
| `data/train_ids.csv` | Material ids used for training/cross-validation. |
| `data/test_ids.csv` | Material ids held out for testing. |
| `data/materials_space_pdos_fingeprints_selected.csv` | A small selected subset of predicted PDOS fingerprints, used e.g. by the similar-materials-search notebook. |
